SELECTED TECHNOLOGIES (with reasons)
--------------------------------------

1. WHATSAPP CONNECTION
   Tool    : whatsapp-web.js (Node.js)
   Why     : Only stable & reliable WhatsApp automation library.
             Python has no equivalent. Works via QR scan.

2. BACKEND
   Tool    : Node.js + Express.js
   Why     : Same JS ecosystem as whatsapp-web.js + Next.js.
             Fast, async, non-blocking. Industry standard.

3. DATABASE
   Tool    : MongoDB Atlas (Cloud)
   Why     : No local install needed. Free tier available.
             Flexible JSON-like storage for messages & rules.
             URL: https://www.mongodb.com/atlas

4. AI AUTO REPLY
   Tool    : Google Gemini API (gemini-1.5-flash)
   Why     : FREE to use. Fast & smart contextual replies.
             Best option vs OpenAI (free tier, no card needed).
             URL: https://aistudio.google.com

5. REAL-TIME UPDATES
   Tool    : Socket.IO
   Why     : Live message feed on dashboard without page refresh.
             Works natively with Node.js.

6. FRONTEND DASHBOARD
   Tool    : Next.js 14 (App Router)
   Why     : Best React framework. Server + client components.
             Fast, SEO-ready, easy routing.

7. STYLING
   Tool    : Tailwind CSS
   Why     : Fast UI development. Works perfectly with Next.js.

========================================================================

FINAL ARCHITECTURE
------------------

  [WhatsApp Phone]
        |
  [whatsapp-web.js]
        |
  [Node.js + Express]  <--->  [MongoDB Atlas]
        |
  [Gemini AI API]         (stores messages & rules)
        |
  [Socket.IO]
        |
  [Next.js 14 Dashboard]
  http://localhost:3000

========================================================================

QUICK REPLY LOGIC
-----------------

  Message received
       |
       v
  Keyword in MongoDB? --YES--> Send stored reply
       |
       NO
       |
       v
  Gemini AI --> Smart reply --> Send to WhatsApp --> Save to MongoDB

========================================================================

COMMANDS TO START
-----------------

  # Backend
  cd backend
  npm install
  node server.js
  (Scan QR shown in terminal with WhatsApp)

  # Frontend (new terminal)
  cd frontend
  npm install
  npm run dev
  (Open: http://localhost:3000)

========================================================================

ENV SETUP NEEDED
----------------

  backend/.env
    GEMINI_API_KEY=<get from aistudio.google.com>
    MONGODB_URI=<get from MongoDB Atlas dashboard>
    PORT=5000

  frontend/.env.local
    NEXT_PUBLIC_API_URL=http://localhost:5000
    NEXT_PUBLIC_SOCKET_URL=http://localhost:5000
